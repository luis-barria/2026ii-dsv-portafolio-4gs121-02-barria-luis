Política de seguridad de contenidos

La política CSP se construyó partiendo de una configuración restrictiva con default-src 'self'. Posteriormente se habilitaron únicamente los recursos necesarios para el funcionamiento del sitio, incluyendo Google Fonts y el mapa de OpenStreetMap, manteniendo el principio de mínimo privilegio.

script-src style-src font-src img-src media-src object-src frame-src base-uri form-action
Directivas de la política y por qué están
Directiva Valor Por qué
default-src 'self' Regla por defecto: solo recursos del propio sitio.

La directiva frame-ancestors no está activa en este proyecto porque GitHub Pages no permite configurar cabeceras HTTP personalizadas. Esta directiva solamente funciona cuando es enviada por el servidor mediante una cabecera HTTP y no desde una etiqueta meta.

La validación del navegador no protege

Durante la demostración se eliminó el atributo required desde las herramientas de desarrollo del navegador y fue posible enviar el formulario sin completar todos los campos obligatorios. También se comprobó que algunos valores pueden modificarse desde el navegador antes de ser enviados. Esto demuestra que las validaciones del lado del cliente mejoran la experiencia de usuario, pero no constituyen una medida de seguridad real. La validación de los datos debe realizarse también en el servidor.
