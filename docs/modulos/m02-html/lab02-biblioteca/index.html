¿Qué es el préstamo a domicilio?

El préstamo a domicilio es un servicio que permite a las personas usuarias retirar materiales bibliográficos para consultarlos fuera de la biblioteca durante un período determinado.

Los libros de la Colección General pueden prestarse para llevar a casa, respetando las normas establecidas por la biblioteca.

Ejemplares disponibles para préstamo

Los siguientes ejemplares pueden solicitarse mediante el servicio de préstamo:

  • Ejemplar 2 disponible para préstamo.
  • Ejemplar 3 disponible para préstamo.
  • Ejemplar 4 disponible para préstamo.

La abreviatura ej. se utiliza para identificar cada copia disponible de un mismo título.

Renovación de préstamos

Para renovar un préstamo se deben cumplir las siguientes condiciones:

  1. El usuario no debe tener multas pendientes.
  2. El usuario no debe tener adeudos con la biblioteca.
  3. El ejemplar no debe estar reservado por otra persona.
  4. La renovación puede realizarse hasta tres veces.

Reglamento

Los préstamos a domicilio podrán renovarse hasta tres veces, siempre que la persona usuaria no mantenga multas, adeudos o restricciones vigentes.

Fuente: Reglamento de Servicios Bibliotecarios del Sistema de Bibliotecas

Recomendación

Antes de solicitar un préstamo, consulta el catálogo de libros disponibles.
